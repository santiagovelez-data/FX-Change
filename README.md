## Description

This application allows users to convert currencies from and to a list of currencies. It also provides historical data and exchange rate trends for the last 10 years.

The most challenging part of this project was understanding how to use the Frankfurter API to retrieve exchange rates and how to display the data in a user-friendly way.

In the future, I would like to add a currency investment calculator that allows users to calculate how much money they would have if they invested in a certain currency for a specific period of time.
